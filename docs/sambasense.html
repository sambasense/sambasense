Overview

SambaSense is a comprehensive Samba configuration and management application for Linux and macOS. It provides both a powerful CLI and an intuitive GUI to install, configure, and manage Samba shares with ease.

Built with Python 3.10+ and PyQt6, SambaSense delivers a modern Material Design-inspired interface with true dark mode support and gold (#FFD700) accent colors. Whether you prefer command-line efficiency or graphical convenience, SambaSense has you covered.

Features

📦 Install / Uninstall

Install or remove Samba, smbclient, and cifs-utils with a single command. Auto-detects your distribution and uses the appropriate package manager.

📂 Configure Shares

Add, edit, and remove Samba shares visually or via CLI. Validates configuration before applying changes.

🔗 Map Network Shares

Mount and unmount remote CIFS/SMB shares with persistent fstab support. Securely stores credentials.

📊 Storage Dashboards

View local shares and mounted remote shares with colorful ASCII bar charts in CLI or interactive graphs in GUI.

🌐 Multi-Distro Support

Works on Arch, Fedora, Debian, Ubuntu, and macOS 14+ (Sonoma through Tahoe). Auto-detects your OS.

🎨 Modern Dark UI

Material You-inspired design with deep black backgrounds, gold accents, and customizable theme colors.

🔒 Security Focused

Uses secure credential file storage for CIFS mounts, no plain-text passwords in process listings.

⚡ Fast CLI

Full-featured command-line interface with 14 subcommands. Scriptable and pipeline-friendly.

Installation

SambaSense is available in multiple package formats for different Linux distributions. Choose your preferred method:

Debian / Ubuntu

sudo dpkg -i sambasense_1.1.1.deb
sudo apt-get install -f

Fedora / RHEL

sudo dnf install sambasense-1.1.1-1.fc40.noarch.rpm

Arch Linux

sudo pacman -U sambasense-1.1.1-1-any.pkg.tar.zst

AppImage (Portable)

chmod +x SambaSense-x86_64.AppImage
./SambaSense-x86_64.AppImage

Flatpak

flatpak install SambaSense.flatpak
flatpak run com.sabyla.SambaSense

From Source

pip install -e .
sambasense --help

Requirements

  • Python 3.10 or higher
  • PyQt6 6.5 or higher (for GUI)
  • samba - Server and client utilities
  • smbclient - SMB client utilities
  • cifs-utils - CIFS mounting utilities (Linux)

install Install Samba packages
sambasense install

Automatically installs Samba, smbclient, and cifs-utils using your distribution's package manager. Requires root privileges.

uninstall Uninstall Samba packages
sambasense uninstall

Prompts for confirmation, then removes Samba packages. Requires root privileges.

enable Enable and start Samba service
sambasense enable

Enables Samba service to start on boot and starts it immediately. Uses systemctl enable --now.

disable Stop and disable Samba service
sambasense disable

Stops the Samba service and disables it from starting on boot.

share add Add a new Samba share
sambasense share add --name NAME --path PATH [options]
--name, -n Share name (required)
--path, -p Directory path to share (required)
--comment, -c Share description/comment
--readonly Make share read-only (default: writable)
--guest Allow guest/anonymous access 
# Add a writable share
sambasense share add --name docs --path /srv/samba/docs

# Add read-only guest share
sambasense share add --name public --path /srv/public --readonly --guest
share remove Remove a Samba share
sambasense share remove --name NAME
--name, -n Share name to remove (required) 
sambasense share remove --name oldshare
share validate Validate smb.conf configuration
sambasense share validate [options]
--verbose, -v Show full testparm output 
sambasense share validate
# Output: Configuration valid.
mount Mount a remote CIFS/SMB share
sambasense mount REMOTE LOCAL [options]
REMOTE Remote share (e.g., //server/share) (required)
LOCAL Local mount point (required)
--user, -u SMB username
--password, -P SMB password (or will prompt) 
# Mount with credentials
sambasense mount //192.168.1.10/share /mnt/nas -u myuser -P mypass

# Interactive password prompt
sambasense mount //nas.local/docs /mnt/docs -u admin
umount Unmount a mounted share
sambasense umount LOCAL
LOCAL Local mount point to unmount (required) 
sambasense umount /mnt/nas
